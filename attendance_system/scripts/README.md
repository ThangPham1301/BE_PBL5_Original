# Scripts

Các công cụ chạy thủ công, không được import vào luồng khởi động Django.

- `face_recognition/diagnostic.py`: kiểm tra model, serializer, API và URL nhận diện khuôn mặt.
- `face_recognition/compare_webcam_5_angles_mtcnn.py`: chụp và so sánh năm góc khuôn mặt bằng webcam.

Chạy từ thư mục `attendance_system` để các đường dẫn model và output nhất quán.
